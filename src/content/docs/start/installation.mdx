Installation of BeDoc is straightforward and can be done via npm or yarn. BeDoc
requires **Node.js v24 or later** (`engines.node` is `>=24`).

## Installation

BeDoc may be run as a standalone tool or as part of a project.

### Standalone

Installing BeDoc globally enables you to run it from the command line as well
as use it in your projects.

<Tabs>
  <TabItem label="NPM">
  ```bash
  npm i -g @gesslar/bedoc
  ```
  </TabItem>
  <TabItem label="Yarn">
  ```bash
  yarn global add @gesslar/bedoc
  ```
  </TabItem>
</Tabs>

### Project

If you prefer to keep BeDoc local to your project, you can install it as a
development dependency.

<Tabs>
  <TabItem label="NPM">
  ```bash
  npm i -D @gesslar/bedoc
  ```
  </TabItem>
  <TabItem label="Yarn">
  ```bash
  yarn add --dev @gesslar/bedoc
  ```
  </TabItem>
</Tabs>

### No install (npx)

You don't have to install BeDoc at all. `npx` will fetch and run it on demand —
handy for one-off runs, trying it out, or CI steps where you'd rather not add a
dependency.

```sh
# Run the latest published version directly
npx @gesslar/bedoc --version

# Generate docs in a single shot
npx @gesslar/bedoc -l lpc -f markdown -i "src/**/*.c" -o docs
```

:::tip
If BeDoc is already a dependency of your project, plain `npx bedoc` will use the
locally installed copy instead of downloading it.
:::

## Verifying Your Installation

After installation, you can confirm that BeDoc is available by running:

<Tabs>
  <TabItem label="Global Install">
  ```sh
  bedoc --version
  ```
  </TabItem>
  <TabItem label="Local Install">
  ```sh
  npx bedoc --version
  ```
  </TabItem>
</Tabs>

To see available options, run:

<Tabs>
  <TabItem label="Global Install">
  ```sh
  bedoc --help
  ```
  </TabItem>
  <TabItem label="Local Install">
  ```sh
  npx bedoc --help
  ```
  </TabItem>
</Tabs>
